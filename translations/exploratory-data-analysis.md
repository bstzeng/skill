# 探索性資料分析

## 概覽

對多個領域的科學資料檔進行完整的探索性資料分析（EDA）。本技能提供自動的檔案類型偵測、格式專屬分析、資料品質評估，並產生適合用於文件記錄與下游分析規劃的詳細 markdown 報告。

**主要能力：**
- 自動偵測並分析 200 多種科學檔案格式
- 完整擷取格式專屬的中繼資料
- 資料品質與完整性評估
- 統計摘要與分布
- 視覺化建議
- 下游分析建議
- 產生 Markdown 報告

## 何時使用本技能

在以下情況使用本技能：
- 使用者提供一個科學資料檔的路徑要分析
- 使用者要求「探索」「分析」或「摘要」一個資料檔
- 使用者想了解科學資料的結構與內容
- 使用者在分析之前需要一份資料集的完整報告
- 使用者想評估資料品質或完整性
- 使用者詢問某個檔案適合做什麼類型的分析

## 支援的檔案類別

本技能完整涵蓋科學檔案格式，分為六大類：

### 1. 化學與分子格式（60 多種副檔名）
結構檔、計算化學輸出、分子動力學軌跡與化學資料庫。

**檔案類型包括：** `.pdb`、`.cif`、`.mol`、`.mol2`、`.sdf`、`.xyz`、`.smi`、`.gro`、`.log`、`.fchk`、`.cube`、`.dcd`、`.xtc`、`.trr`、`.prmtop`、`.psf` 等。

**參考檔案：** `references/chemistry_molecular_formats.md`

### 2. 生物資訊與基因體格式（50 多種副檔名）
序列資料、比對、註解、變異與表現量資料。

**檔案類型包括：** `.fasta`、`.fastq`、`.sam`、`.bam`、`.vcf`、`.bed`、`.gff`、`.gtf`、`.bigwig`、`.h5ad`、`.loom`、`.counts`、`.mtx` 等。

**參考檔案：** `references/bioinformatics_genomics_formats.md`

### 3. 顯微鏡與影像格式（45 多種副檔名）
顯微鏡影像、醫學影像、全玻片影像與電子顯微鏡。

**檔案類型包括：** `.tif`、`.nd2`、`.lif`、`.czi`、`.ims`、`.dcm`、`.nii`、`.mrc`、`.dm3`、`.vsi`、`.svs`、`.ome.tiff` 等。

**參考檔案：** `references/microscopy_imaging_formats.md`

### 4. 光譜與分析化學格式（35 多種副檔名）
NMR、質譜、IR/拉曼、UV-Vis、X 光、層析與其他分析技術。

**檔案類型包括：** `.fid`、`.mzML`、`.mzXML`、`.raw`、`.mgf`、`.spc`、`.jdx`、`.xy`、`.cif`（晶體學）、`.wdf` 等。

**參考檔案：** `references/spectroscopy_analytical_formats.md`

### 5. 蛋白質體與代謝體格式（30 多種副檔名）
質譜蛋白質體、代謝體、脂質體與多體學資料。

**檔案類型包括：** `.mzML`、`.pepXML`、`.protXML`、`.mzid`、`.mzTab`、`.sky`、`.mgf`、`.msp`、`.h5ad` 等。

**參考檔案：** `references/proteomics_metabolomics_formats.md`

### 6. 一般科學資料格式（30 多種副檔名）
陣列、表格、階層式資料、壓縮封存檔與常見的科學格式。

**檔案類型包括：** `.npy`、`.npz`、`.csv`、`.xlsx`、`.json`、`.hdf5`、`.zarr`、`.parquet`、`.mat`、`.fits`、`.nc`、`.xml` 等。

**參考檔案：** `references/general_scientific_formats.md`

## 最佳實務

### 閱讀參考檔案

參考檔案很大（每份 10,000 字以上）。要有效率地使用它們：

1. **依副檔名搜尋：** 用 grep 找到特定的格式
   ```python
   import re
   with open('references/chemistry_molecular_formats.md', 'r') as f:
       content = f.read()
       pattern = r'### \.pdb[^#]*?(?=###|\Z)'
       match = re.search(pattern, content, re.IGNORECASE | re.DOTALL)
   ```

2. **擷取相關章節：** 不要不必要地把整份參考檔案載入上下文

3. **快取格式資訊：** 如果要分析多個同類型的檔案，重用格式資訊

### 資料分析

1. **對大型檔案抽樣：** 對於有數百萬筆紀錄的檔案，分析具代表性的樣本
2. **優雅地處理錯誤：** 許多科學格式需要特定的函式庫；提供清楚的安裝說明
3. **驗證中繼資料：** 交叉檢查中繼資料的一致性（例如宣告的維度 vs 實際資料）
4. **考量資料來源：** 記下儀器、軟體版本、處理步驟

### 產生報告

1. **完整：** 包含下游分析所需的所有相關資訊
2. **具體：** 依檔案類型提供具體的建議
3. **可執行：** 建議具體的下一步與工具
4. **附程式碼範例：** 示範如何載入與處理資料

## 進階用法

### 多檔案分析

分析多個相關檔案時：
1. 對每個檔案分別進行 EDA
2. 建立一份摘要比較報告
3. 找出關聯與相依
4. 建議整合策略

### 品質控管

評估資料品質時：
1. 檢查格式是否合規
2. 驗證中繼資料的一致性
3. 評估完整性
4. 找出離群值與異常
5. 與預期的範圍／分布比較

### 前處理建議

依資料特性，建議：
1. 標準化策略
2. 缺失值補值
3. 離群值處理
4. 批次效應校正
5. 格式轉換
