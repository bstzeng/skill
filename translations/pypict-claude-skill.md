# PICT 測試設計器

本技能使用 PICT（成對獨立組合測試）進行有系統的測試案例設計。給定需求或程式碼，它會分析系統以找出測試參數、產生帶有適當限制條件的 PICT 模型、執行模型以產生成對的測試案例，並將結果與預期輸出一起格式化。

## 何時使用本技能

在以下情況使用本技能：
- 為有多個輸入參數的功能、函式或系統設計測試案例
- 為有許多組合的設定建立測試組
- 需要以最少的測試案例達到完整的涵蓋
- 分析需求以找出測試情境
- 處理有多條條件路徑的程式碼
- 為 API 端點、網頁表單或系統設定建立測試矩陣

## 工作流程

依以下流程設計測試：

### 1. 分析需求或程式碼

從使用者的需求或程式碼中找出：
- **參數**：輸入變數、設定選項、環境因素
- **數值**：每個參數可能的值（使用等價類別劃分）
- **限制條件**：商業規則、技術限制、參數之間的相依
- **預期結果**：不同的組合應該發生什麼

**分析範例：**

對於一個需求如下的登入函式：
- 使用者可以用帳號／密碼登入
- 支援兩步驟驗證（開／關）
- 在信任的裝置上記住登入
- 失敗 3 次後限制速率

找出的參數：
- 憑證：有效、無效
- 兩步驟驗證：啟用、停用
- 記住我：勾選、未勾選
- 先前失敗次數：0、1、2、3、4

## 疑難排解

### 沒有產生任何測試案例

- 檢查限制條件是否過度嚴格
- 確認限制條件的語法（必須以 `;` 結尾）
- 確保限制條件中的參數名稱與定義相符（使用 `[ParameterName]`）

### 測試案例太多

- 確認使用的是 2 階（成對）而不是更高階
- 考慮拆成子模型
- 檢查參數能否分成獨立的測試組

### 輸出中有無效的組合

- 加入缺少的限制條件
- 確認限制條件的邏輯正確
- 檢查是否需要使用 `NOT` 或 `<>` 運算子

### 腳本錯誤

- 確保已安裝 pypict：`pip install pypict --break-system-packages`
- 檢查 Python 版本（3.7+）
- 確認模型語法有效
