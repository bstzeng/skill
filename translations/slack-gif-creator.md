# Slack GIF 製作器

一套為 Slack 製作最佳化動畫 GIF 的工具與知識。

## Slack 規格要求

**尺寸：**
- 表情符號 GIF：128x128（建議）
- 訊息 GIF：480x480

**參數：**
- FPS：10–30（越低檔案越小）
- 色彩：48–128（越少檔案越小）
- 長度：表情符號 GIF 保持在 3 秒以內

### 讓圖形好看

圖形應該看起來精緻有創意，而不是陽春。做法如下：

**使用較粗的線條** ——外框與線條一律設定 `width=2` 或更高。細線（width=1）看起來斷續又業餘。

**增加視覺深度**：
- 背景使用漸層（`create_gradient_background`）
- 疊加多個形狀增加複雜度（例如星星裡面再放一顆較小的星星）

**讓形狀更有趣**：
- 不要只畫一個單純的圓——加上高光、圓環或圖樣
- 星星可以有光暈（在後方畫較大、半透明的版本）
- 組合多種形狀（星星 + 閃光、圓 + 圓環）

**注意色彩**：
- 使用鮮豔、互補的色彩
- 增加對比（淺色形狀配深色外框，深色形狀配淺色外框）
- 考慮整體構圖

**對於複雜形狀**（愛心、雪花等）：
- 組合多邊形與橢圓
- 仔細計算點位以保持對稱
- 加入細節（愛心可以有一道高光弧線，雪花有精緻的分枝）

發揮創意、注重細節！一個好的 Slack GIF 應該看起來很精緻，而不是像占位圖形。

## 動畫概念

### 抖動/震動
以振盪偏移物件位置：
- 用影格索引搭配 `math.sin()` 或 `math.cos()`
- 加入小幅的隨機變化，讓感覺更自然
- 套用到 x 和/或 y 位置

### 脈動/心跳
有節奏地縮放物件大小：
- 用 `math.sin(t * frequency * 2 * math.pi)` 產生平滑的脈動
- 心跳效果：兩下快速脈動後暫停（調整正弦波）
- 在基本大小的 0.8 到 1.2 倍之間縮放

### 彈跳
物件落下並彈起：
- 落地時用 `interpolate()` 搭配 `easing='bounce_out'`
- 落下時（加速）用 `easing='ease_in'`
- 每一格增加 y 速度來模擬重力

### 旋轉
讓物件繞中心旋轉：
- PIL：`image.rotate(angle, resample=Image.BICUBIC)`
- 要有搖晃效果：角度用正弦波而不是線性變化

### 淡入/淡出
逐漸出現或消失：
- 建立 RGBA 圖片並調整 alpha 通道
- 或使用 `Image.blend(image1, image2, alpha)`
- 淡入：alpha 從 0 到 1
- 淡出：alpha 從 1 到 0

### 滑入
把物件從畫面外移到定位：
- 起始位置：影格邊界之外
- 結束位置：目標位置
- 用 `interpolate()` 搭配 `easing='ease_out'` 平滑停下
- 要有過衝效果：用 `easing='back_out'`

### 縮放
以縮放與定位做出拉近拉遠效果：
- 拉近：從 0.1 縮放到 2.0，裁切中心
- 拉遠：從 2.0 縮放到 1.0
- 可以加入動態模糊增加戲劇性（PIL 濾鏡）

### 爆炸/粒子噴發
建立向外放射的粒子：
- 以隨機的角度與速度產生粒子
- 更新每個粒子：`x += vx`、`y += vy`
- 加入重力：`vy += gravity_constant`
- 隨時間淡出粒子（降低 alpha）

## 最佳化策略

只有在被要求縮小檔案大小時，才實作以下其中幾種方法：

1. **更少的影格** ——降低 FPS（用 10 而不是 20）或縮短長度
2. **更少的色彩** ——用 `num_colors=48` 而不是 128
3. **更小的尺寸** ——用 128x128 而不是 480x480
4. **移除重複影格** ——在 save() 中設定 `remove_duplicates=True`
5. **表情符號模式** ——`optimize_for_emoji=True` 會自動最佳化

## 理念

本技能提供：
- **知識**：Slack 的規格要求與動畫概念
- **工具**：GIFBuilder、驗證器、緩動函式
- **彈性**：用 PIL 的基本圖形建立動畫邏輯

它「不」提供：
- 死板的動畫模板或預先寫好的函式
- emoji 字型渲染（在不同平台上不可靠）
- 內建於技能中、預先打包好的圖形庫

**關於使用者上傳的注意事項**：本技能不包含預先做好的圖形，但如果使用者上傳了圖片，就用 PIL 載入並處理它——依他們的請求判斷是要直接使用，還是只當作靈感。

發揮創意！組合各種概念（彈跳 + 旋轉、脈動 + 滑入等），並充分運用 PIL 的能力。
