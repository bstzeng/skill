# Vibe 知識短影片導演

把使用者的主題直接製作成可播放成片。延續《二向箔》案例的視覺語言與製作質量，為新主題重新設計內容、物體與解釋動畫。

## 環境與首次配置

本技能不繫結模型廠商。由所在代理的檔案、終端、聯網研究和圖片檢視工具執行；無需 Codex 專屬工具。宿主安裝與呼叫見 [相容說明](references/compatibility.md)。先執行 scripts/doctor.py 檢查依賴。沒有影象檢視能力時可以渲染，但應將視覺驗收交給可看圖的工具或人工，不能聲稱已審片。

首次設定配樂：將 assets/local-profile.example.json 複製為技能目錄 local-profile.json（僅本地保留）並填入音樂路徑，或設定 VIBE_MUSIC，或給 prepare.py 傳 --music。首次配置後可只提交主題。公開包不含歌曲、商用字型或個人路徑。

## 輸入與預設成片

唯一必需輸入是主題。使用者新要求優先於預設值；沒有指定時直接執行，不重複詢問時長、顏色、音樂、解析度或是否開始。

- 中文；60 秒；9:16；1440×2560 原生渲染；恆定 30fps；MP4 / H.264 / yuv420p / BT.709；AAC 48kHz 雙聲道。
- 無配音、無解說旁白；用運動過程、對照和短文字講清楚。
- 前 3 秒有與主題相關的視覺衝擊或懸念；第一秒已有主體和鉤子文字。
- 深黑背景、冰藍與香檳金、精細線框與粒子、剋制輝光、留白、大字號中文。
- 預設使用使用者已配置的配樂；案例使用《千年之後（氛圍版）》60 秒片段，不代表已獲得公開分發或商用授權。使用者選擇新曲後，分析真實音軌；公共技能不捆綁歌曲。
- 以成片為完成標準。只交文案、分鏡、網頁或靜音動畫不算完成；使用者明確只要其中一項時按其範圍執行。

## 執行流程

1. **獨立專案。** 執行 `scripts/prepare.py --topic '主題' --project 'work/vibe-短名'`。指令碼複製案例、節奏資料和預設配置，生成 brief.json；它不生成新主題動畫。不要覆蓋既有成片。臨時檔案放 work/，交付放當前任務規定的 outputs/。
2. **核查與敘事。** 對關鍵結論查閱可靠一手來源；將主張、來源、事實/假說/類比/虛構的區分寫入專案 sources.md。提取一個主問題、兩到三個解釋步驟和一個收束。科幻不能包裝成已證實物理；不能為反轉編造事實。
3. **導演分鏡。** 讀取 [視覺與敘事標準](references/direction.md)。先設計開場變化，再確定每鏡要讓觀眾看懂什麼。把文字、起止幀、動作、事實屬性、音樂事件寫入 storyboard.json。60 秒通常約 7–9 段，按內容調整。
4. **配樂卡點。** 讀取專案 brief.json 的 music 與 beat_analysis_status。只有雜湊、起點和長度吻合的案例片段才複用分析；其餘配樂執行 scripts/analyze_music.py，並重寫動作時間對映。BPM 只是輔助，轉場與動作對齊真實音訊事件，按 30fps 量化，不能憑空填節拍。輕音效服務於動作。
5. **新主題動畫。** 讀取 [渲染說明](references/rendering.md)，以專案 film.js 為可執行案例。保留排版與底層繪圖方法，重寫場景、主體動畫、標籤和事件對映。不能僅替換文字而留下二向箔物體或舊論證。可按主題選 Canvas、Three.js 或其他原生代碼渲染方式。
6. **預覽再渲染。** 檢視開場 0 / 0.8 / 1.6 / 3 秒、各段中點、轉場前後及結尾的實際圖片，修復缺字、遮擋、太暗和字小問題。同步更新案例的預覽時間點。渲染真正的 1440×2560、30fps 影片。
7. **混音匯出。** 用 `scripts/finish.py --silent 靜音成片 --music 音軌 --output 輸出路徑 --duration 60`，可選 `--sfx 音效.wav`、`--music-start 秒數`。助手負責生成與本片動作一致的音效。工具完成混音、編碼、全片解碼、規格校驗、抽幀和技術報告。
8. **驗收交付。** 檢視 contact.jpg，複雜運動另看連續幀；檢查字形、閱讀時間、開場事件、圖形因果和結尾。讀取響度報告，確認非靜音且無削波。能試聽時試聽；只有訊號檢查時不聲稱已試聽。修復後使用宿主支援的檔案附件或本地檔案連結交付 MP4，具備預覽工具時開啟預覽，簡短註明時長與規格。

## 缺失資訊與範圍

沒有參考片時使用已儲存案例，不再次要求參考檔案。預設音樂缺失時，檢查已提供素材及 本地配置中的路徑，繼續指令碼和畫面工作，並只詢問實際缺失的音軌。不得把自制臨時音軌冒充原曲或完成版。

不自動釋出、不建立定時任務、不購買素材或呼叫付費渲染服務；這些不屬於“主題出片”的預設範圍。

## 資源

- assets/reference-film.js：已交付二向箔動畫程式碼，用於複用繪圖方法與視覺樣式。
- assets/music-analysis.json、assets/beat-edit.json：該版真實音軌的分析與事件時間，不是所有歌曲通用節拍。
- assets/local-profile.example.json：一次性配樂配置示例；scripts/doctor.py 檢查渲染環境。
- scripts/prepare.py、analyze_music.py、finish.py：建專案、音軌分析、混音匯出與技術檢查。
