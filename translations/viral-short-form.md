# 爆款短影音內容

幫助使用者發想並撰寫能抓住注意力、贏得收藏的短內容（TikTok、Reels、YouTube Shorts 與輪播）。本技能收錄了開場鉤子、留存、格式與平台適配的經驗證模式。它不預測爆紅。它是在堆疊勝算，讓使用者從經驗證的結構出發，而不是面對一張白紙。

## 搭配技能（深入其中一部分）

這是總括技能。若要深入單一平台或工作流程的某一部分，Vyral 的 repo 也提供：

- `viral-hooks`：跨任何平台的開場鉤子生成與批評。
- `viral-tiktok-content`：TikTok 專屬的腳本、推薦頁（FYP）機制、熱門音效、原生功能。
- `viral-youtube-shorts`：Shorts 策略、導向長片的漏斗、營利試算。
- `viral-instagram-reels`：Reels、試用 Reels、每觸及分享數、原創性規則。
- `viral-short-form-ideas`：發想系統、內容支柱、挖掘題材、內容再利用。
- `viral-captions-and-ctas`：說明文字、畫面文字、主題標籤、CTA、置頂留言。

當問題只針對單一平台或單一部分時，使用其中之一。這個總括技能仍負責端到端的工作。

## 運作原則（先讀，全程套用）

1. **收藏與完播才是訊號；觀看數只是虛榮。** 每個選擇都以「有人會收藏這個／看兩遍嗎」來最佳化，而不是原始觸及。
2. **是模式比對，不是預測。** 絕不承諾某個東西會爆紅。說明什麼*通常*有效以及為什麼。誠實就是品牌。
3. **一律提供多個、多樣的選項。** 一個開場只是猜測。橫跨不同類型的 6–10 個才是策略。絕不只交回一個點子。
4. **具體勝過聰明。** 具體的名詞、數字與利害關係，每次都勝過模糊的小聰明。
5. **開場就是全部。** 前 1–3 秒決定其他內容有沒有被看到。按比例把力氣花在那裡。
6. **承諾要與回報相符。** 誇大影片內容的開場會毀掉信任與收藏。不要做沒有兌現的標題黨。

## 工作流程

依請求調整。不要盤問使用者。如果他們想快速拿到開場，就直接跳到步驟 3，其餘自行推斷。

1. **釐清需求**（只問真正缺少的）：產品或主題、受眾、目標（觸及 vs. 收藏 vs. 轉換）、平台、任何格式偏好，以及硬性限制（長度、不露臉、品牌規則）。
2. **選擇適合訊息的格式** → `references/formats.md`。
3. **產生開場鉤子。** 6–10 個分散在不同類型，而不是同一個的變化版 → `references/hooks.md`。
4. **為留存設計結構。** 建立 鉤子 → 升溫 → 回報 → CTA，並主動避開三種失敗模式 → `references/retention.md`。
5. **平台適配檢查。** 長度、畫面文字、字幕、音效、節奏、安全區 → `references/platforms.md`。
6. **誠實收尾並安排迭代。** 設定期望，建議發文量，並加碼表現好的內容 → `references/metrics-honesty.md`。

## 模式（依使用者的要求分派）

- **「給我開場鉤子」** → 步驟 3（加上簡單的步驟 1）。回傳一組依類型標示的開場，然後提議把最強的發展成腳本。
- **「寫一支腳本」** → 步驟 1–5，使用 `assets/script-template.md`。
- **「改善我的腳本／開場」** → 批評模式。對照 `references/retention.md` 中的三種失敗模式診斷。具體指出注意力在*哪裡*、*為什麼*下滑，然後改寫弱的段落。用 `assets/hook-checklist.md` 檢查開場。
- **「做一組輪播」** → `assets/carousel-outline.md` + `references/formats.md`。
- **「把這個再利用」** → 把一個點子、腳本或長片變成多支*不同的*短片或格式（每支都有不同的開場 + 格式，而不是複製）→ `references/formats.md`。

## 範例

**使用者：**「給我一支推出 39 美元可重複使用冷萃咖啡壺的影片開場。」

**好的回應：** 推斷需求（產品上市、可能是 TikTok／Reels、目標＝收藏），然後回傳 6–10 個 **依類型標示** 的開場，每個都先給回報、而且具體。例如：

- *賣關子：*「我找到唯一一個我真的會回購的咖啡小物。品牌先不說。」
- *花費告白：*「我花了 400 美元買咖啡器材，讓你可以直接跳到這個 39 美元的。」
- *唱反調：*「你那套昂貴的咖啡設備，正是咖啡變難喝的原因。」

然後提議把最強的發展成腳本（`assets/script-template.md`）。絕不只回傳一個開場，絕不以品牌開頭，絕不承諾它會爆紅。
