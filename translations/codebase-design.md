# 程式碼庫設計

設計**深模組**：小介面背後有大量行為，放在乾淨的接縫上，並能透過該介面測試。凡是在設計或重構程式碼的地方，都使用這套語言與原則。目標是為呼叫者提供槓桿、為維護者提供區域性、為所有人提供可測試性。

## 詞彙表

精確使用這些術語：不要用「元件」「服務」「API」或「邊界」替代。一致的語言正是重點所在。

**模組（Module）**：任何具有介面與實作的東西。刻意不限尺度：一個函式、類別、套件，或跨越多層的切片。_避免_：單元、元件、服務。

**介面（Interface）**：呼叫者要正確使用模組所必須知道的一切：型別簽章，但也包括不變式、順序限制、錯誤模式、必要的設定，以及效能特性。_避免_：API、簽章（太狹隘，它們只指型別層面）。

**實作（Implementation）**：模組內部的東西，它的程式碼本體。與**轉接器**不同：一個東西可以是小轉接器搭配大實作（一個 Postgres repository），也可以是大轉接器搭配小實作（一個記憶體中的假物件）。當接縫是話題時用「轉接器」；其他情況用「實作」。

**深度（Depth）**：介面上的槓桿。呼叫者（或測試）每學習一個單位的介面，能運用多少行為。當大量行為位於小介面之後，模組就是**深的**；當介面幾乎和實作一樣複雜時，就是**淺的**。

**接縫（Seam）**_（Michael Feathers）_：一個不必在該處編輯就能改變行為的地方；模組介面所在的*位置*。接縫放在哪裡本身就是一個設計決策，與接縫後面放什麼不同。_避免_：邊界（與 DDD 的限界上下文意義重疊）。

**轉接器（Adapter）**：在接縫上滿足介面的具體東西。描述的是*角色*（填哪個位置），而不是內容（裡面有什麼）。

**槓桿（Leverage）**：呼叫者從深度中得到的東西。每學習一個單位的介面就能得到更多能力。一份實作在 N 個呼叫點與 M 個測試中回本。

**區域性（Locality）**：維護者從深度中得到的東西。變更、bug、知識與驗證集中在一處，而不是散佈在各呼叫者之間。修一次，處處修好。

## 原則

- **深度是介面的性質，而不是實作的性質。** 一個深模組內部可以由小型、可 mock、可替換的部件組成；它們只是不屬於介面。模組可以有**內部接縫**（實作私有，供自己的測試使用），也有位於其介面上的**外部接縫**。
- **刪除測試。** 想像刪掉這個模組。如果複雜度消失了，它只是一個轉手的中介。如果複雜度在 N 個呼叫者之間重新出現，它就有存在的價值。
- **介面就是測試面。** 呼叫者與測試跨越同一個接縫。如果你想*越過*介面去測試，這個模組的形狀大概不對。
- **一個轉接器代表假想的接縫。兩個轉接器才代表真實的接縫。** 除非真的有東西會在接縫兩側變化，否則不要引入接縫。

## 為可測試性而設計

好的介面讓測試變得自然：

1. **接受相依，不要自己建立相依。**

   ```typescript
   // Testable
   function processOrder(order, paymentGateway) {}

   // Hard to test
   function processOrder(order) {
     const gateway = new StripeGateway();
   }
   ```

2. **回傳結果，不要產生副作用。**

   ```typescript
   // Testable
   function calculateDiscount(cart): Discount {}

   // Hard to test
   function applyDiscount(cart): void {
     cart.total -= discount;
   }
   ```

3. **小的表面積。** 方法越少 = 需要的測試越少。參數越少 = 測試設定越簡單。

## 關係

- 一個**模組**恰好有一個**介面**（它呈現給呼叫者與測試的表面）。
- **深度**是**模組**的性質，以其**介面**來衡量。
- **接縫**是**模組**的**介面**所在之處。
- **轉接器**位於**接縫**上，並滿足**介面**。
- **深度**為呼叫者帶來**槓桿**，為維護者帶來**區域性**。

## 不採用的框架

- **以實作行數對介面行數的比例衡量深度**（Ousterhout）：這會獎勵把實作灌水。我們改用「深度即槓桿」。
- **把「介面」當成 TypeScript 的 `interface` 關鍵字或類別的公開方法**：太狹隘：這裡的介面包含呼叫者必須知道的每一項事實。
- **「邊界」**：與 DDD 的限界上下文意義重疊。請說**接縫**或**介面**。
