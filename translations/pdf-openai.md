# PDF 技能

## 何時使用
- 讀取或審閱版面與視覺很重要的 PDF 內容。
- 以程式建立格式可靠的 PDF。
- 在交付前驗證最終的渲染結果。

## 工作流程
1. 優先做視覺審閱：把 PDF 頁面渲染成 PNG 並檢查。
   - 如果有 `pdftoppm` 就使用它。
   - 如果沒有，安裝 Poppler，或請使用者在本機審閱輸出。
2. 建立新文件時，使用 `reportlab` 產生 PDF。
3. 使用 `pdfplumber`（或 `pypdf`）擷取文字與快速檢查；不要依賴它來確保版面還原度。
4. 每次有意義的更新之後，重新渲染頁面並確認對齊、間距與可讀性。

## 暫存與輸出慣例
- 中間檔案使用 `tmp/pdfs/`；完成後刪除。
- 在這個 repo 中工作時，把最終產出物寫在 `output/pdf/` 之下。
- 保持檔名穩定且具描述性。

## 品質要求
- 維持精緻的視覺設計：一致的字體排印、間距、邊界與章節層級。
- 避免渲染問題：被裁切的文字、重疊的元素、破損的表格、黑色方塊或無法閱讀的字符。
- 圖表、表格與圖片必須清晰、對齊，並有清楚的標示。
- 只使用 ASCII 連字號。避免 U+2011（不換行連字號）與其他 Unicode 破折號。
- 引用與參考資料必須是人類可讀的；絕不留下工具 token 或占位字串。

## 最終檢查
- 在最新的 PNG 檢查顯示零視覺或格式瑕疵之前，不要交付。
- 確認頁首/頁尾、頁碼與章節轉換看起來精緻。
- 保持中間檔案有條理，或在最終核准後移除。
