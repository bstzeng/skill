# Markdown 轉 EPUB 技能

本技能把 Markdown 文件轉換成專業的 EPUB 電子書檔案。非常適合把研究文件、部落格文章、文章或聊天對話摘要，轉換成可攜、不限裝置的電子書格式。

## 概覽

本技能接受多種格式的 Markdown 內容，並產生格式正確的 EPUB3 檔案，可在所有主要的電子書閱讀器上使用，包括：
- Apple Books
- Amazon Kindle（透過 Mac／Windows／iOS／Android 版 Kindle）
- Google Play 圖書
- Kobo 與其他 EPUB 閱讀器
- 任何標準的 EPUB 閱讀器

## 運作方式

1. **解析 Markdown**：分析你的 Markdown，並自動：
   - 把 H1 標題（`#`）視為章節邊界
   - 把 H2 標題（`##`）視為章節內的小節標題
   - 保留格式（粗體、斜體、連結、清單、程式碼區塊）

2. **產生結構**：建立正確的 EPUB 結構：
   - 從章節自動產生目錄
   - 導覽文件（EPUB3 標準）
   - 中繼資料（標題、語言等）

3. **建立檔案**：產生有效、可直接下載使用的 EPUB3 檔案

## 取得最佳結果的提示

1. **使用正確的 Markdown 結構**：Markdown 遵循標準慣例（H1 作為標題、H2 作為小節）時，本技能效果最好

2. **清楚的章節分隔**：用 H1 標題清楚標出章節分隔

3. **具描述性的標題**：標題會成為目錄，所以要讓它們清楚且具描述性

4. **內容組織**：在標題之間有邏輯地放置內容

5. **支援的格式**：使用基本的 Markdown 格式，以在所有閱讀器上獲得最佳相容性

## 疑難排解

**EPUB 打不開**：確保你的 Markdown 格式正確。檢查連結的括號是否成對、語法是否正確。

**目錄是空的**：確保你的 Markdown 包含定義章節的 H1 標題。

**格式看起來不一樣**：EPUB 閱讀器會套用自己的字型與樣式。這是正常且預期的行為。
