# HyperFrames 創意

品牌、節奏、風格、旁白與構圖方向。在 `hyperframes-core` 的技術契約就緒後使用。

動態模式、場景藍圖、轉場與 CSS 標記效果，請使用 `hyperframes-animation`——本技能刻意不涉及動畫。

> **任何不簡單的合成，都要「先」讀這兩份——它們會覆蓋你做網頁的直覺：**
>
> * `references/house-style.md` ——「詮釋提示詞、產生真實內容」、偷懶預設值清單，以及背景/前景圖層做法。這就是把字面上的重新上色變成一個*概念*的關鍵。
> * `references/video-composition.md` ——影片媒介的尺度、深度與前景細節。它說明如何避免空洞的網頁式版面，而不強加一個通用的元素數量。
>
> 略過這兩份，是產出普通、像網頁的結果最大的單一原因。它們不是下方路由表中的選讀項目——任何超過一行的修改，在選色或寫 HTML 之前，兩份都要打開。
