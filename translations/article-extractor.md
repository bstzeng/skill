# 文章擷取器

本技能從網路文章與部落格文章中擷取主要內容，移除導覽、廣告、電子報訂閱與其他雜訊。儲存乾淨、易讀的文字。

## 何時使用本技能

當使用者有以下情況時啟用：
- 提供一個文章／部落格網址，並想要文字內容
- 要求「下載這篇文章」
- 想要「擷取 [URL] 的內容」
- 要求「把這篇部落格文章存成文字」
- 需要沒有干擾的乾淨文章文字

## 運作方式

### 優先順序：
1. **檢查工具是否已安裝**（reader 或 trafilatura）
2. 使用最佳的可用工具 **下載並擷取文章**
3. **整理內容**（移除多餘的空白、適當地格式化）
4. 以文章標題作為檔名 **儲存成檔案**
5. **確認位置** 並顯示預覽

## 錯誤處理

### 常見問題

**1. 工具沒有安裝**
- 嘗試替代工具（reader → trafilatura → 備案）
- 提議安裝：「用 npm install -g reader-cli 安裝 reader」

**2. 付費牆或需要登入**
- 擷取工具可能會失敗
- 告知使用者：「這篇文章需要認證，無法擷取。」

**3. 無效的 URL**
- 檢查 URL 格式
- 嘗試跟隨與不跟隨重新導向

**4. 沒有擷取到內容**
- 網站可能大量使用 JavaScript
- 嘗試備案方法
- 擷取失敗時告知使用者

**5. 標題中有特殊字元**
- 為檔案系統清理標題
- 移除：`/`、`:`、`?`、`"`、`<`、`>`、`|`
- 換成 `-` 或直接移除

## 輸出格式

### 儲存的檔案包含：
- 文章標題（如有）
- 作者（工具有提供時）
- 文章主要內文
- 章節標題
- 沒有導覽、廣告或雜訊

### 會被移除的內容：
- 導覽選單
- 廣告與促銷內容
- 電子報訂閱表單
- 相關文章側欄
- 留言區（選用）
- 社群媒體按鈕
- Cookie 通知

## 取得最佳結果的提示

**1. 大多數文章使用 reader**
- 最全面的工具
- 以 Firefox 閱讀模式為基礎
- 適用於大多數新聞網站與部落格

**2. 以下情況使用 trafilatura：**
- 學術文章
- 新聞網站
- 版面複雜的部落格
- 非英文內容

**3. 備案方法的限制：**
- 可能包含一些雜訊
- 段落偵測較不準確
- 對簡單的網站來說總比沒有好

**4. 檢查擷取品質：**
- 一律向使用者顯示預覽
- 詢問看起來是否正確
- 需要時提議改用其他工具
