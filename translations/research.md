description: 以高可信度的第一手來源調查一個問題，並把發現整理成 repo 中的一份 Markdown 檔。當使用者想研究某個主題、蒐集文件或 API 事實，或把閱讀的苦工交給背景代理時使用。
---

啟動一個**背景代理**來做研究，讓你在它閱讀時可以繼續工作。以全新的上下文視窗啟動它。

它的工作：

1. 以**第一手來源**（官方文件、原始碼、規格、官方 API）調查問題，而不是別人對它們的二手整理。把每一項主張追溯回擁有它的來源。
2. 把發現寫進單一的 Markdown 檔，並為每項主張引用來源。
3. 存放在 repo 已經保存這類筆記的地方；配合既有慣例，如果沒有，就放在合理的位置並說明在哪裡。
